# Documentos sin revisión

Estos documentos se movieron aquí tal como estaban, solo reordenados por tema y
renombrados según su contenido. **No se han revisado**: pueden estar
desactualizados, mezclar contratos con notas de trabajo o describir cosas que el
proyecto ya no hace. No los tomes como referencia del estado actual.

En el futuro se ordenarán bien: se revisará cada uno contra el código, se
reescribirá lo vigente y se descartará el resto.

- `p2p/`: plan, progreso, modelo de amenazas y auditoría del primer hito.
- `protocolo/`: protocolo entre pares, emparejamiento e identidad.
- `transporte/`: LAN, Internet, TURN, privacidad de red, recuperación e ICE.
- `sync/`: ledger, sesión y rondas de Sync, bóveda sincronizada y claves sintéticas.
- `dispositivos-android/`: interoperabilidad, vinculación, API y UI de dispositivos.
- `escritorio-kde/`: integración KDE, auditoría de diseño y D-Bus.
- `evidencia/`: registros fechados de pruebas y mediciones.
- `capturas/`: imágenes usadas por los documentos.
